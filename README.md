# Portal DST Apps

Portal katalog layanan internal DST yang dibangun dengan Astro dan menyediakan pencarian layanan serta pengelolaan katalog oleh admin.

Deskripsi paragraf pertama setelah judul ini digunakan otomatis sebagai deskripsi pada halaman utama Astro. Jika deskripsi berubah, halaman akan mengikuti perubahan tersebut pada build atau server berikutnya.

## Menjalankan proyek

```sh
npm install
npm run dev
```

Variabel environment disimpan di `.env` lokal dan tidak boleh di-commit. Gunakan `.env.example` sebagai template.
